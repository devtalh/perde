## Decisions for review

- The overnight task explicitly allows height 0.5..9, adds ownerName/allowed-player names, and says the front faces the placer. These more specific instructions govern this implementation despite older 1x1/placement wording in SPEC. SPEC and AGENTS are unchanged.
- The 16:9 UI helper rounds the derived height to the server's required 1/16 grid. For arbitrary sixteenth widths, exact 16:9 and exact sixteenth heights cannot both hold. Defaults (4 x 2.25) and the requested test size (8 x 4.5) are exact.
- Invalid/non-finite saved geometry falls back to safe defaults; malformed saved URL becomes empty, malformed access mode becomes OWNER_ONLY. Unowned command-placed blocks are operator-administered.
- Basic server runDir isolation moved into F1A-1 because its boot check must already avoid the old `run/` server and port 25565. Player1/Player2 run configuration documentation follows in F1A-4.
- The verified `submitCustomGeometry` + `RenderTypes.text` method is hosted by a BlockEntityRenderer, which 26.2 supports directly; immutable extracted geometry/text are submitted through the same vanilla node collector. The global-renderer mechanism is the available vanilla solution for geometry outside the source block. Phase 2 must still test the actual oversized block with Entity Culling/MoreCulling.
- With 16:9 lock enabled (default), width drives height and the height slider is disabled. Unlock it for independent height. Geometry sends on mouse release, keyboard release or leaving a dirty keyboard slider.
- Every C2S edit also requires the last server-opened panel to match its block and dimension. This prevents delayed packets after dimension changes or edits without a server-authorized panel. State changes still use only vanilla BE sync. Online names are matched case-sensitively; offline lookup uses verified `UUIDUtil.createOfflinePlayerUUID`, with vanilla-compatible 1..16 ASCII player-name validation.
- Notion's hub predates the GO decision and vanilla S2C sync decision. Repository SPEC and the explicit overnight task take precedence. Linear issues LEA-189..192 were read; its shared field-notes endpoint still returns `Tool get_agent_context not found`.
